## For CP-68b (cards and spacing): exactly what this branch changed, so there is ONE card
This branch was built before the 68a/68b split reached it, so it holds card rules. All are in `apps/web/components/blocks.css` and
`apps/web/app/globals.css`; `components/cards.tsx` is untouched.
- Tokens (`docs/frontend/tokens.json`): `radius-card` 12px, `radius-control` 8px, `radius-small` 4px, `space-card` 20px,
  `space-card-tight` 16px, `shadow-card` (hairline + faint shadow), `shadow-lift` (hover), `shadow-pop` (menus, sheets),
  `motion-fast` 150ms, `motion-base` 200ms, `motion-ease`, `motion-lift` translateY(-1px), `state-wait-fill`.
- `.b-card`: white, `radius-card`, `box-shadow: var(--elev)` where `--elev` defaults to `shadow-card`. `.b-card-h` and `.b-card-b`
  now pad with `space-card` (tight under 700 px) and the head has no tinted band. `.b-card-pad` is a padded card body.
- A bare `.b-card` (no `.b-card-h` / `.b-card-b` child) gets `space-card-tight` padding.
- A card inside `.b-card`, `.b-dpanel` or `.b-details` is a flat `surface` tile with no edge (no box in a box).
- Lift: `a.b-card`, `a.b-prow`, `.b-kitem`, `a[data-lift]` set `--elev: shadow-lift` and `transform: motion-lift` on hover.
- Subject stripes (inset 3–4 px) removed from `.b-prow`, `.b-cell`, `.b-peek`, `.b-level` and `timetable.css`.
- Today: `.b-today-block` is a section (no background, edge or radius); `.b-today-sum` has a hairline under it; `.b-today-body` has no
  side padding. The cards inside it are ordinary `.b-card`s.
- The older pages' `.panel` / `.panel-head` / `.panel-body` (globals.css): hairline `line`, `radius-card`, `space-card` padding.
- `.b-actionrow` (the Screen's action row) takes no grid row when empty.
- u90 holds: card radius 12, first text ≥ 12 px in from a card's edge, no card with an edge inside a card.
