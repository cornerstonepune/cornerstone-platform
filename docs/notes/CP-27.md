# CP-27: trim the backend to its target tables

The census of live is `CP-27-census.md`. This note is the branch's own (docs/notes/README.md).

## Group 1: word lists become rules, and tables nothing uses leave

Migration `20270125190000_cp27_word_lists_and_dead_tables.sql`, one transaction under `db push`. Tables in `public` and
`pii`: 170 → 150; functions in `public`, `internal` and `pii`: 159 → 152 (`supabase/table-budget.json`).

A table with rows on live is never dropped: what is needed is copied, a block raises unless every value is in its new
home, and the table moves to the schema `retired` (no grants, keys, triggers or policies). The three empty ones are
dropped after a block raises unless each is still empty. An unknown word anywhere rolls the whole migration back
(rehearsed: an extra `note_status` row left 170 tables and no `retired` schema).

## Verified

- `bin/testdb fresh` builds with every migration; 150 tables in `public` and `pii`, 152 functions; `apply_conventions()`
  passes; `engine live rules --url …` → 0 rules held otherwise (rules.json rewritten from that build).

  voice note and claim, a confirmed micro-step link): `engine past` fingerprints (evidence, states, scored answers,
  questions, levels) equal before and after; every retired table's row count equal before and after (the counts above,
  `item_registry_skill` 28,700 there); the 13 role-group pairs equal; the colour words equal; sessions unchanged. An
  extra word in `note_status` made the migration raise and roll back whole.
- Engine suite (4,230 tests, `-n 4`): 4,211 passed; every failure re-run alone passes except the three that fail on main
  too, here (`test_spine_provenance` x2: the NCERT PDF cannot be fetched through this proxy; `test_web_identity`: a
  `?host=` socket URL the website's driver refuses). `bin/check`, `ruff format --check`, `ruff check`: clean.
- Website: `npm run lint` clean; `tsc --noEmit` gives the same 2 errors as main (`LayoutProps`, a Next-generated type).
- `bin/specs CP-1 CP-3 CP-4 CP-5 CP-9 CP-10 CP-13`: CP-1, CP-5, CP-9, CP-10, CP-13 pass as on main. CP-3 item 7 and CP-4
  item 6 fail here and pass on main: both are git-diff guards against changing browser tests (CP-3, when its proofs
  change) or lowering an engine test file's test or assert count (CP-4), and this change rewrites exactly the tests
  listed above. Neither guard was loosened.
