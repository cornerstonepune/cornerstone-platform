# CP-63: Today in blocks

Issue #796. Web only; no migration, no engine change, no model.

## Verified
- `cd apps/web && TEST_DATABASE_URL=… npx playwright test --project=steps tests/p63-today-in-blocks.spec.ts` → 6 passed.
- Other Today specs green: u90, u13-needs-you, u60, s41, u25, u26, u1, u15, u96, u65, u51.
- `bin/check` green. eslint clean on the changed files; tsc shows only the generated `LayoutProps` names.
- One spec changed, and why: u90 "choosing a lesson opens the lesson panel beside the day" now says a period opens in the timetable's own panel for that day (the thing Nimish asked for); the Today row is no longer a toggle, so its `aria-expanded` line went.
- **A hazard in the shared test database, fixed at its cause.** The engine's timetable loader refuses to write while any fortnight of the same academic year is frozen ("Fortnight 90 is frozen: give a reason to change it"). u90 froze a fortnight in the shared 2031-32 year, and only the order the specs run in (u75 and u82 first) kept it from breaking their loads on a copy that had run it before. CP-63's own spec, and now u90, make an academic year of their own (labels 2035-36 and 2036-37), so no spec freezes a fortnight in the shared year. Tests only.
- On a FRESH database (`bin/testdb fresh`), run in CI's order, `p63`, `u75`, `u82`, `u90` → u75, u82, p63 pass. u90's "B1b right: a row opens on the right…" fails there, and fails the same way on plain `origin/main` (b9d2877) on a fresh database when u90 runs alone: it depends on rows other specs leave. Not this PR's.

## What changed
- `today/blocks.tsx`: `TodayBlock` (a section with its own heading), `PapersBlock` (one small card per assessment with answers waiting: title, class and day, "n answers to judge", one button to the first paper to judge; the same reads as the Assessments board, so an educator sees their own classes and a coordinator the school's; six cards, then "n more"), `NotesBlock`.
- Educator's Today: Teach today (the periods; each links to `/timetable?view=day&day=…&class=…&open=lesson:<id>`; a link opens the whole day), then Papers to check, Notes to confirm, then the existing "Waiting on you" under its own heading. The coordinator's Today gets Papers to check and Notes to confirm between its tiles and "Waiting on you".
