# CP-29: the go-live route (issue 620, part of 586)

`POST /timetable/go-live` (in `engine/api/routes/timetable_hand.py`): CP-22's `tt_live.go_live` for the site, answering
`Report.changes()` (every session moved, every lesson removed, how many added, each date's counts). No table, function
or migration. Tests: `tests/api/test_timetable_go_live_route.py`.

## For the frontend / to check
- The "moved" list is wider than a hand swap: CP-22 re-matches each subject's lessons in plan order, so one swap can
  move several sessions. The test pins it to exactly the sessions whose date or period changed in the database.
- A refusal is a 409 with CP-22's own words; a stranger is a 403; no draft placed is a 409.
- Not verified: a run on a copy of live (no schema change, so no rehearsal needed).
