## Next.js advisories

Read on 9 Nov 2026 from the GitHub advisory database (github.com/advisories), npm package `next`:

- **GHSA-2464-fhr4-w9xw**: "Next.js: Unauthenticated Remote Code Execution in Image Optimization API when SVG files are
  used". Affected: `>= 10.0.0, <= 15.5.27` and `>= 16.0.0, <= 16.4.0`. Patched: `15.5.28` and `16.4.1`.
- **GHSA-673q-mjm6-r5xr**: "Next.js: Unauthenticated Remote Code Execution in `use cache` functions returning typed
  arrays". Affected: `>= 16.0.0, <= 16.4.0`. Patched: `16.4.1`.

The first fixed 16.x version for both is 16.4.1. The site was on 16.3.5 (affected by both).

Version chosen: 16.4.5

Why 16.4.5 and not 16.4.1: it is the newest 16.4 patch (npm `latest`, published 3 Nov 2026) and the reviewer's
suggestion, so the later 16.4 patch fixes come with it; it is the same minor version, so no new API. `eslint-config-next`
moves with it, as it always has (the two are kept at one version).
