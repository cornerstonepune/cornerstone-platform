# CP-28: the school's Today counts (issue 617, part of 595)

One read-only route for the coordinator's Today: `POST /k2/today-school` (actor in, whole numbers and class codes out).
No table, no function, no migration. Code: `engine/w3_read/today_school.py`; tests: `tests/test_today_school.py`.

## Decisions to check (mine, not the school's)
- **Moved counts as taught** in "sessions done of planned" (the wireframe's 118 + 13 = 131 only adds up that way).
- A class-day cell is `not_done` if any planned lesson is not done *or still unconfirmed* (a lesson last week still on
  `planned`), else `moved`, else `done`; `holiday` from `school_day`; `none` where a teaching day had no planned lesson
  (not in the spec's four words; the screen can leave it blank).
- A draft = the newest *placed* run of a class and fortnight that has not started and has no `timetable_live` approval.
- Consent = latest answer of each child enrolled now is `given`.
- "New next week" = used in next week's lessons and in no lesson before next week (any class, any state).
- Clashes: not accepted, in fortnights not yet ended, filtered to the campus through the classes in `places`.
