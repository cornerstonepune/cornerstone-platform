# UI-14: tokens, fonts and the existing parts on them

Branch `ui-14-tokens-fonts`, issue #526. Design choices: `specs/UI-14/design.md`.

- `apps/web/scripts/tokens.mjs` makes `design-system/tokens.css` from `docs/frontend/tokens.json` and copies the logo
  files; `scripts/contrast.mjs` writes `docs/design-tokens-contrast.md`. `tests/u14-ui-tokens.spec.ts` runs both with
  `--check`. Change a colour: edit `docs/frontend/tokens.json`, run `node apps/web/scripts/tokens.mjs` and
  `node apps/web/scripts/contrast.mjs`.
- The site stays light (`data-scheme="light"` on `<html>`); dark values exist and are used only by tests until the screens
  are restyled (UI-13, UI-2).
- Lesson: Tailwind v4's `theme` layer defines its own `--font-sans`/`--font-serif`; the tokens layer must come after it.
- Lesson: a Playwright spec under `apps/web/tests` runs only if its name matches a project's `testMatch`
  (`[sumpe]<n>-*.spec.ts` for the steps project).
