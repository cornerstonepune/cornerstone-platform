## PR body
Fixes #946 (ADR 0112): `engine enrol class` enrols a child whose list birthday cell is blank with `pii.child.birthday`
NULL. A blank never overwrites a held birthday (the update is skipped when there is no birthday). A written but bad
birthday still refuses the run, and the range refusal now says "a class list" instead of K2.
Checks: the two target test files pass (19); ruff lint and format pass; `bin/check --claude` shows no failure. The core
suite has one scan test that fails in the full run and passes alone (order-dependent, unverified).
