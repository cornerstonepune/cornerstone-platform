Skill set · Grades 1 to 4

Counting and place value

A skill set is what the school teaches and tests together, from one to four grades. It points at the skills the system reads a child on; it never scores a child itself.

Each level in a sentence
Easy
Counts the bundles of ten, with a prompt.
Medium
Counts in tens up to 50 with bundles.
Hard
Counts in tens up to 100 and adds loose ones.
Advance
Says how many without recounting.
