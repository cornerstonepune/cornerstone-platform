# CP-85: Materials that are alternatives ("pencils or crayons")

The activity notes say "Puppets or flashcards": either one will do. Today the split would make both needed, so the class list,
the school's list and the buy list ask for both.

## Done when

1. An activity's materials can group items as alternatives; the group is kept on the activity's link to its items.
2. A class's list shows one line for a group (the first alternative unless the educator picks another) and names the others on it.
3. The school's list and the buy list count one alternative per group.
4. The catalogue fill marks alternatives where the note says "or" between items, with the existing checks; anything it cannot
   tell goes to a person.

## Out of scope

Choosing the cheapest alternative from stock or price; alternatives across activities.
